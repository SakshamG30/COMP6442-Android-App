# AncestraWell  
**A Mobile App for Social and Emotional Wellbeing**  

[![App Logo](https://github.com/SakshamG30/COMP6442-Android-App/blob/main/src/app/src/main/res/drawable/login_welcome.png)](https://github.com/SakshamG30/COMP6442-Android-App)  

## 🌟 Overview  
AncestraWell is a culturally sensitive mobile application designed to support the social and emotional wellbeing of Aboriginal and Torres Strait Islander communities. Aligned with the **Close the Gap** initiative, our app bridges cultural divides while providing:  

- **Community Connection**: Real-time chat and event coordination  
- **Data Insights**: Graphical visualization of wellbeing statistics  
- **Personalized Profiles**: Culturally-tailored user experiences  
- **Secure Platform**: End-to-end encrypted communications  

Built with:  
🔥 **Firebase** (Auth, Realtime DB, Firestore)  
📱 **Android Studio** (Java)  
⚙️ **Industry Standards** (SOAP, REST, MVC/MVVM patterns)  

---

## ✨ Key Features  
| Feature | Description | Tech Used |  
|---------|-------------|-----------|  
| **Secure Auth** | SHA-256 encrypted logins | Firebase Auth |  
| **Live Data** | 2500+ suicide prevention records | Firestore, JSON/CSV |  
| **Smart Search** | NLP-powered query parsing | AVL Trees, Tokenizers |  
| **Real-Time Chat** | P2P messaging with notifications | Realtime DB |  
| **Responsive UI** | Portrait/landscape adaptive layouts | XML, ConstraintLayout |
